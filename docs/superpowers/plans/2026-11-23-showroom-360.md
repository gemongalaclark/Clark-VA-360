# Showroom 360 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A mock Cebu used-car dealer website with a public side (`/showroom`) and a hidden admin (`/showroom/admin`). Everything is saved in the visitor's browser.

**Architecture:**
- A lazy-loaded app inside the Vite portfolio.
- Pure logic lives in `showroomRules.js`, tested with `node --test`.
- Data sits in IndexedDB behind a small `store.js` plus a `useShowroom()` hook, synced across tabs with BroadcastChannel.
- Public and admin views are plain React components styled with CSS modules.

**Tech Stack:** React 18, CSS modules, lucide-react, browser APIs only.

**Spec:** `docs/superpowers/specs/2026-11-23-showroom-360-design.md`

## Global Constraints
- No new npm packages.
- No commits unless Clark asks. Clark commits himself, and work happens in the main working tree (CarMark precedent).
- Folder: `FRONTEND/src/components/SHOWROOM 360/`.
- Brand:
  - red `#cb2525` (hover `#ea4343`)
  - ink `#0F172A`, slate `#1E293B`
  - page `#F8FAFC`, border `#E2E8F0`, muted `#475569`
  - Poppins headings, Inter body 16px, tabular numbers
  - lucide icons at stroke 1.75, no emoji in the UI
  - light theme only
- "Not stated" is never shown as "No". Unknown condition and paper values render as their own state.
- No real business, person or phone number in the sample data. The shop is "Demo Motors Cebu" with phone `0900 000 0000`.
- Accessibility: touch targets ≥44px, visible focus, aria-labels on icon buttons, errors next to fields, `prefers-reduced-motion` honoured.
- Don't touch `CARMARK 360/dealerList.js`. Import from CarMark only `MODELS` (for name suggestions and seed price sanity).

## Review Focus
1. **Corrupt or old IndexedDB data, or a private window with no IndexedDB.** The app must still render, using the seed in memory and a visible "can't save in this browser" notice, never a blank page.
2. **Big phone photos (12 MP HEIC/JPEG).** Resize must not hang or crash, and unreadable files show a field error.
3. **Event edge times.** A car is live exactly at `startsAt`, not at `endsAt`. When a car's cash price is edited below its sale price, the sale price is ignored.
4. **Deleting a car that is in an event, has leads or is featured.** Events drop the item. Leads keep the `carLabel` snapshot and show "car removed".
5. **Deep links to unknown car ids, or `/showroom/admin/<garbage>`.** Show a "not found" state with a way back, never a crash.

### Task 1: Rules (pure logic) + tests

**Files:** Create `showroomRules.js` and `showroomRules.test.js`.

**Produces** (all named exports):
- **Display and stock numbers**
  - `COLORS`: `{key:{label,hex}}`.
  - `carTitle(car)` returns `"2019 Toyota Vios 1.3 E AT"`. The suffix is AT, MT or CVT, and a blank variant is skipped.
  - `formatPeso(n)` returns `"₱548,000"`.
  - `nextStockNo(cars)` returns the highest number + 1, zero-padded to 4 digits. Empty gives `SR-0001`.
- **Events and prices**
  - `eventStatus(ev, now)`: `upcoming` / `live` / `ended`. Live means `startsAt <= now < endsAt`.
  - `effectivePrice(car, events, now)` returns `{price, original, event}`. The sale applies only when the car is in a live event and `salePrice < car.price`; otherwise `original` and `event` are `null`.
- **Featured and sold rows**
  - `featuredCars(cars, events, now, max = 8)`:
    - live-event cars with status available come first, then `featured` available cars, newest listed first, deduped;
    - if the result is empty, return the 5 newest available cars.
  - `recentlySold(cars, n = 6)`: sold cars by `soldAt`, newest first.
- **Financing**
  - `loanQuote(price, downPct, term, fin)` returns `{down, financed, monthly, allIn}`:
    - `down = round(price × downPct / 100)`
    - `monthly = ceil(financed × (1 + addOn[term] / 100) / term)`
    - `allIn = down + round(price × feesPct / 100)`
  - `monthlyFrom(price, fin)` is `loanQuote` at `minDownPct` and the longest term, returning `.monthly`.
- **Search and URLs**
  - `filterCars(cars, query, events, now)`:
    - excludes sold cars;
    - `q` matches make, model, variant, year, color label and stockNo, case-insensitive, and every word must match;
    - other filters: make, body, transmission, fuel, priceMin, priceMax and onSale, which all use the effective price; yearMin and yearMax;
    - sort `newest` (default, by listedAt), `price-asc`, `price-desc`, `km-asc`, `year-desc`.
  - `parseQuery(search)` / `toQuery(query)` round-trip a URL query and drop empty values.
- **Days in stock:** `daysInStock(car, now)` counts whole days since `listedAt`. `AGING_DAYS = 60`.
- **Validation**
  - `isPhMobile(s)` accepts `09XXXXXXXXX` or `+639XXXXXXXXX`, ignoring spaces and dashes.
  - `validateCar(car)` returns `{field: message}`:
    - required: year, make, model, transmission, fuel, odometer, price;
    - year must be between 1980 and current year + 1;
    - odometer must be 0 or more and under 1,000,000;
    - price must be over 0.
  - `validateEvent(ev, events, cars)` returns `{field | 'items': message}`:
    - name is required;
    - end must be after start;
    - each `salePrice` must be above 0 and below the car's price;
    - a car may not be in another event whose range overlaps.
  - `validateLead(lead, todayISO)`:
    - name is required;
    - mobile must pass `isPhMobile`;
    - a test drive needs a date, which can't be before today, and a slot.
- **Messages**
  - `inquiryText(car, priceInfo, lang)`. EN gives `"Hi! I'm interested in the {title} ({stockNo}, {price}). Is it still available?"`; CEB gives `"Hi! Interested ko sa {title} ({stockNo}, {price}). Available pa ni?"`.
  - `fbCaption(car, settings, priceInfo, lang)`: the title, price (or sale price with the original as "was ₱…"), "from ₱X/mo" when the car has financing, key facts (year · km · transmission · fuel), condition items that are `yes`, shop name, phone and address, and hashtags `#CebuCars #UsedCarsCebu #{Make}`. It contains no URL.

- [ ] **Step 1: Write the failing tests.** Cover each export with the exact values above. Include:
  - `eventStatus` at exactly `startsAt` gives live, and at `endsAt` gives ended.
  - `effectivePrice` ignores a sale price ≥ the cash price.
  - `featuredCars` puts event cars first, dedupes, falls back to 5 newest, and excludes sold and reserved.
  - `loanQuote(500000, 30, 60, defaults)` gives `{down:150000, financed:350000, monthly:ceil(350000×1.4432/60)=8419, allIn:175000}`.
  - `isPhMobile` accepts `"0917 123 4567"` and `"+639171234567"`, and rejects `"12345"`.
  - `validateEvent` flags an overlapping car and passes back-to-back events (end == next start).
  - `fbCaption` has no `http`.
  - `nextStockNo([])` gives `SR-0001`.

### Task 2: Seed, store, i18n, car art

**Files:**
- Create `seedData.js`, `store.js`, `i18n.js` and `CarArt.jsx`.
- Add seed tests to `showroomRules.test.js`.

**Interfaces:**
- **Consumes:** Task 1's rules.
- **Produces**
  - **Seed data**
    - `makeSeed(now: Date)` returns `{cars, events, leads:[], settings}`. It has 12 cars from CarMark models. 3 are featured, 2 are sold (soldAt within the last 3 weeks), 1 is reserved, and `listedAt` is spread 3–95 days before `now`. It has 1 event, "Christmas Sale", running from now − 3 days to now + 30 days, with 3 available cars at sale prices below their cash price.
    - `DEFAULT_SETTINGS`.
  - **Store**
    - `useShowroom()` returns `{ready, persistent:bool, cars, events, leads, settings, saveCar, deleteCar, saveEvent, deleteEvent, saveLead, saveSettings, addPhoto(file)→id, photoUrl(id)→string|null, removePhotos(ids), resetDemo}`.
    - IndexedDB name `showroom360`, version 1, with stores `cars`, `events`, `leads`, `kv` (settings) and `photos` (Blob).
    - It seeds on first open.
    - It posts `'changed'` on `BroadcastChannel('showroom360')`, and other tabs reload when they receive it.
    - If IndexedDB fails, it falls back to the in-memory seed with `persistent:false`.
    - `deleteCar` also removes the car's photos and its event items.
  - **Photos:** `resizeImage(file, maxEdge = 1600, quality = 0.82) → Promise<Blob>`, using `createImageBitmap` and a canvas. It rejects on undecodable files.
  - **i18n:** `t(lang, key, vars)`, `LANGS = ['en','ceb']`, and `useLang()`, which persists in localStorage `showroom360:lang`. Unknown keys fall back to English.
  - **Car art:** `<CarArt body color />`, an inline SVG silhouette for each body type, filled with `COLORS[color].hex`.

- [ ] **Step 1: Write the failing tests.**
  - Every seed car passes `validateCar`.
  - Each seed car's price is inside the matching CarMark generation's `price.min..max` (looked up by a `genId` field kept on the seed record).
  - The seed event is `live` at `now`, and its items pass `validateEvent`.
  - Seed stock numbers are unique.
  - No seed text contains a phone number other than `0900 000 0000`.
- [ ] **Step 2:** Run the tests. Expected: FAIL.
